# Deception Engine

Phase 4 implements static, deterministic deception only. Active database configuration maps fixed HTTP paths to inert synthetic response modes. Every successful resolution records centralized telemetry; Phase 5 may subsequently attach a documented deterministic assessment contribution without changing the decoy response. Honeytoken material is CHIMERA-specific, hashed in the registry, non-functional, and never accepted by authentication.

The deception engine performs no behavior-based activation, scoring, blocking, external callback, filesystem access, command execution, or vulnerability-lab integration. Adaptive presentation remains deferred to a separately authorized future phase. See [CYBER_DECEPTION.md](CYBER_DECEPTION.md).
